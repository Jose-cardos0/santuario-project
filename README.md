# Santuário da Divina Misericórdia  

Um site arrojado e inovador desenvolvido para apresentar o Santuário da Divina Misericórdia, oferecendo uma experiência digital rica, interativa e espiritualmente edificante.  

## Tecnologias Utilizadas  

- **ReactJS:** Framework JavaScript para a construção de interfaces de usuário modernas e dinâmicas.  
- **TailwindCSS:** Framework de CSS utilitário para estilização eficiente e responsiva.  
- **API da Bíblia Diária:** Integração que fornece versículos e mensagens bíblicas diárias.  

## Funcionalidades  

- Design responsivo e elegante, acessível em dispositivos móveis e desktops.  
- Versículos diários atualizados automaticamente via API.  
- Navegação intuitiva e experiência imersiva para os usuários.  

## Objetivo  

Promover a fé e a espiritualidade por meio de uma plataforma digital moderna, conectando pessoas de diferentes lugares ao Santuário da Divina Misericórdia.
